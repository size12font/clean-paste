# Security policy

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities or clipboard-data exposure. Use GitHub's **Report a vulnerability** flow in the repository Security tab so details stay private until a fix is available.

Include the affected macOS version, CleanPaste revision, reproduction steps, and a synthetic test case. Never include real sensitive clipboard content.

## Supported version

Security fixes target the latest revision on the default branch while CleanPaste is in beta.
